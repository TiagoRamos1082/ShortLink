# Requisitos Funcionais

- **RF01:** O sistema deve permitir a criação de links curtos a partir de URLs originais.
- **RF02:** O sistema deve permitir a visualização dos links curtos criados.
- **RF03:** O sistema deve permitir a exclusão dos links curtos criados.

# Requisitos Não Funcionais

- **RNF01:** O sistema deve possuir uma arquitetura organizada em camadas, facilitando a manutenção e a evolução do código.
- **RNF02:** O sistema deve garantir a persistência dos links curtos criados em um banco de dados.

# Regras de Negócio

- **RN01:** Não será permitido editar um link curto após sua criação.
- **RN02:** Futuramente, cada pessoa poderá criar, no máximo, 5 links curtos.
